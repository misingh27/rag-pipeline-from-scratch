# SQL

SQL, or Structured Query Language, is used to interact with relational databases.

A relational database stores data in tables consisting of rows and columns. Each table usually represents an entity or concept, while relationships between tables can be represented using keys.

A primary key uniquely identifies each row in a table. A foreign key creates a relationship between a column in one table and a primary key in another table.

The SELECT statement is used to retrieve data from a database. The WHERE clause filters rows based on conditions.

SQL joins combine data from multiple tables. Common joins include INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN.

GROUP BY groups rows that have the same values in specified columns. Aggregate functions such as COUNT, SUM, AVG, MIN, and MAX can then be applied to each group.

Indexes can improve query performance by allowing the database to locate rows more efficiently. However, indexes also consume storage and can increase the cost of insert and update operations.

SQL is widely used in data engineering, analytics, reporting, and application development.
